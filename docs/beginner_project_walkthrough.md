# 从零读懂这个量化项目

这份讲义以当前项目 `quant_research_v2` 为准。目标不是让你背代码，而是让你知道：

1. 数据从哪里来；
2. 每一列数据是什么意思；
3. 因子如何计算；
4. 模型到底在学习什么；
5. 为什么信号必须在 `T+1` 成交；
6. 如何把预测变成真实股票组合；
7. 回测如何计算现金、持仓、成本和收益；
8. 报告里的每个指标如何理解；
9. 当前结果为什么可信，又还受什么限制。

---

## 1. 一句话理解这个项目

项目做的事情是：

> 每个月最后一个交易日收盘后，比较约287只A股股票的6个历史特征；让简单多因子模型和梯度提升模型分别预测未来哪个股票更强；第二天开盘买入排名最高的20只股票；下个月再调整；扣除手续费、印花税和滑点后，看相对等权股票池是否取得超额收益。

项目不是预测大盘涨跌，也不是预测某只股票明天一定上涨。它做的是“横截面”比较：

```text
同一天，在这批股票中，谁未来一段时间相对更强？
```

这叫作 **横截面选股**。

项目同时保留两套策略：

- `baseline`：简单基线，把6个标准化因子直接等权相加。
- `model`：机器学习模型，使用Python机器学习库scikit-learn的直方图梯度提升模型组合6个因子。

设置简单基线非常重要。如果复杂模型连简单因子打分都比不过，就没有理由增加复杂度。

## 2. 全流程图

```text

    ↓
交易日历对齐、有效性检查
    ↓

    ↓
```

## 4. 数据层：原始数据长什么样

项目读取的是：

```text
F:\quantization_project\data\raw\*.parquet
```

每个文件名就是股票代码，例如：

```text
000001.parquet
600519.parquet
300750.parquet
```

一只股票一天的原始数据主要有：

| 字段 | 含义 | 例子 |
|---|---|---|
| `date` | 交易日 | 2024-01-02 |
| `open` | 当天开盘价 | 10.00 |
| `close` | 当天收盘价 | 10.20 |
| `high` | 当天最高价 | 10.30 |
| `low` | 当天最低价 | 9.90 |
| `volume` | 成交量 | 1,000,000 |
| `amount` | 成交金额 | 10,200,000元 |
| `turnover` | 换手率 | 1.5% |

原始文件还可能包含涨跌幅、涨跌额和股票代码的中文列，但本项目只保留计算需要的字段。

### 4.1 开盘价和收盘价

- `open` 是当天第一笔或集合竞价形成的开盘价格。
- `close` 是当天收盘价格。
- `high` 和 `low` 是当天最高和最低成交价格。

选股信号在 `T` 日收盘后生成，所以策略不可能再用 `T` 日收盘价成交。最早只能在 `T+1` 日开盘成交。

### 4.2 前复权是什么意思

分红、送股、拆股会让价格发生非经济性的跳变。

例如股票10送10，价格从20元变成10元。股票价值并没有突然减少一半，但原始价格变化会制造一个 `-50%` 的假收益。

前复权会调整历史价格，使历史走势和当前价格能够在同一尺度上比较。

当前原始文件来自前复权行情。项目直接使用这些价格计算因子和收益，不再对价格做“均值加减3倍标准差”的整段历史缩尾。

### 4.3 为什么统一交易日历

不同股票可能停牌，或者某天缺少数据。如果每只股票的日期列表长度不同，直接滚动计算和组合计算很容易错位。

项目先收集所有股票出现过的日期，形成统一日历：

```text
2019-01-02
2019-01-03
...
2024-12-31
```

然后让每只股票都对齐到这个日历。某只股票停牌时，当天可能出现空行。

### 4.4 缺失值和非法价格如何处理

项目会检查：

- 同一天是否重复；
- 最高价是否低于最低价；
- 开盘、收盘、最高、最低是否小于等于0；
- 成交量、成交额、换手率是否合法；
- 交易时是否停牌。

不合法的价格不会被当作真实价格参与模型。

如果某天停牌：

- 今天不能交易；
- 组合估值使用最近一次有效收盘价；
- 复牌后的价格仍要进入因子和收益计算。

### 4.5 数据质量结果

当前输出：

```text
股票文件：287
原始加载行数：390,446
日历对齐后的行数：417,872
有效数据覆盖率：92.99%
重复股票日期：0
非法OHLC关系：0
```

“对齐后行数”比原始行数多，是因为统一日历会把停牌和缺失日期也补出来。多出来的空行不等于是有效行情，所以覆盖率只有约93%。

### 4.6 当前数据最大的限制

当前287个文件是**当前沪深300样本附近留下的股票文件**，不是历史时点成分股。

这意味着：

- 回测2019年时，我们可能已经知道哪些公司后来活下来；
- 已经退市或后来被剔除的股票没有完整进入股票池；
- 策略可能带有幸存者偏差。

因此不能把结果叫作“沪深300指数增强”。

### 4.7 基准是什么

项目使用可用股票池的**等权收益**作为基准：

```text
每天所有有效股票收益率的平均值
```

它不是沪深300指数，也不是可交易ETF，只是一个透明的研究基准。

## 5. 因子层：六个因子到底算什么

定义位于 [features.py](../src/quant_research/features.py)。

所谓因子，就是一个可能带有预测能力的数字。

### 5.1 20日动量

```text
momentum_20d(T) = close(T) / close(T-20) - 1
```

意思是从20个交易日前到今天，股价涨了多少。

例如：

```text
今天收盘 12元，20日前收盘 10元
动量 = 12 / 10 - 1 = 20%
```

经济直觉是趋势可能延续。

但短期动量在A股也可能表现为反转，所以不能只凭名字判断方向，必须看RankIC。

### 5.2 60日动量

```text
momentum_60d(T) = close(T) / close(T-60) - 1
```

观察更长的约三个月趋势。

### 5.3 5日反转

先算过去5日收益：

```text
past_5d = close(T) / close(T-5) - 1
```

再取负数：

```text
reversal_5d = -past_5d
```

因此：

- 过去跌得越多，反转因子越大；
- 过去涨得越多，反转因子越小。

经济直觉是短期超跌可能反弹。

### 5.4 20日波动率

先计算每日收益率：

```text
ret(T) = close(T) / close(T-1) - 1
```

再计算最近20个日收益的标准差：

```text
volatility_20d = std(ret, 最近20日)
```

项目定义：

```text
low_volatility_20d = -volatility_20d
```

因此初始含义是“低波动股票得分更高”。但最终因子是否有效仍由数据检验。

### 5.5 20日换手率

```text
turnover_20d = 最近20日换手率均值
low_turnover_20d = -turnover_20d
```

初始假设是低换手可能更有利，因为高换手可能代表拥挤、投机或短期情绪过热。

### 5.6 20日流动性

```text
amount_20d = 最近20日成交额均值
low_liquidity_20d = -log(1 + amount_20d)
```

成交额越小，这个因子越大。

它和换手率的区别是：

- 换手率是相对于流通股本的交易活跃程度；
- 成交额是绝对交易金额。

### 5.7 因子为什么要截面缩尾

同一天内，有些极端值可能非常夸张。项目对每个因子：

1. 只取当天所有股票的值；
2. 找到1%和99%分位数；
3. 把低于1%的值截到1%分位；
4. 把高于99%的值截到99%分位。

这叫每日截面缩尾，使用当天信息，不使用未来日期。

### 5.8 因子为什么要标准化

不同因子的单位不同：

- 动量是百分比；
- 换手率是比例；
- 成交额可能达到亿元；
- 波动率可能是0.02左右。

不能直接相加。

项目用截面Z分数标准化：

```text
z = (x - 当日均值) / 当日标准差
```

这样标准化后的因子大致都以0为中心、以1为尺度，可以比较和相加。

### 5.9 什么是股票可进入组合

项目要求：

- 当天有合法行情；
- 可以交易；
- 至少有60个交易日历史；
- 20日平均成交额不少于1000万元；
- 6个因子都不为空。

这些条件写入 `eligible` 列。

注意：有因子不等于可交易，有价格也不等于可进入组合。

## 6. 标签层：模型要预测什么

定义位于 [labels.py](../src/quant_research/labels.py)。

### 6.1 时间顺序

```text
T日收盘
  ↓ 计算因子、形成信号
T+1日开盘
  ↓ 买入
持有20个交易日
  ↓
T+21日开盘
  ↓ 卖出/计算退出价格
```

所以未来20日收益是：

```text
future_return(T)
= open(T+21) / open(T+1) - 1
```

代码中：

```python
entry_open = open.shift(-1)
exit_open = open.shift(-(20 + 1))
future_return = exit_open / entry_open - 1
```

为什么要这样写？

- 当前行是T；
- `shift(-1)` 取下一行，即T+1；
- `shift(-21)` 取从T往后的第21行；
- 从T+1开盘到T+21开盘，正好约20个交易日。

### 6.2 为什么不用T日收盘到T+21日收盘

因为T日收盘价只有在收盘后才完全确定。若收盘后才产生信号，就不能以T日收盘价买入。

直接使用T日收盘到未来的收益，会把T日收盘到T+1开盘之间的不可交易收益算给策略。

### 6.3 为什么减掉当天平均值

原始未来收益：

```text
股票未来上涨12%
```

但当天整个股票池都涨了10%，股票只超额上涨2%。

项目定义：

```text
target_excess_return
= 股票未来收益 - 当天所有股票未来收益均值
```

这样模型学习的是相对强弱，而不是全市场方向。

### 6.4 排名标签

项目还把每日超额收益转成0到1的排名，再减0.5：

```text
target_rank = 当日排名百分位 - 0.5
```

结果范围大约在 `-0.5` 到 `0.5`。

预测排名比预测具体收益更容易稳定，因为具体收益有大量噪声和极端值。

### 6.5 无穷值和缺失值

如果开盘价为0或缺失，未来收益可能变成无穷大。

项目会把所有非有限数值变成空值。非法价格不能产生有效训练样本。

## 7. 训练集、验证集、测试集

定义位于 [splits.py](../src/quant_research/splits.py)。

| 数据集 | 时间 | 用途 |
|---|---|---|
| 训练集 | 2019-2021 | 拟合模型 |
| 验证集 | 2022 | 比较模型和基线 |
| 测试集 | 2023-2024 | 最终样本外检验 |

### 7.1 为什么不随机抽样

金融数据有时间顺序。今天和昨天的样本高度相关。

如果随机把某些日期的股票放进训练集，把相邻日期的股票放进测试集：

- 未来信息可能泄漏；
- 测试结果会非常乐观；
- 实盘中不会拥有这种优势。

### 7.2 为什么需要剔除跨期标签

一个2021年12月20日的样本，它的20日未来收益要用2022年1月价格。

如果这个样本进入训练集，验证集就会“被未来标签看见”。

项目规则是：

```text
训练样本的label_end_date必须早于验证期开始
验证样本的label_end_date必须早于测试期开始
```

当前结果：

```text
训练标签最后一天：2021-12-31
验证标签最后一天：2022-12-30
```

这保证了训练标签不跨入2022，验证标签不跨入2023。

### 7.3 测试集为什么不能反复调参

如果每看一次测试结果就改参数，测试集事实上也变成了训练数据。

正确流程：

1. 用训练集拟合；
2. 用验证集比较方法；
3. 锁定方案；
4. 最后查看一次测试集；
5. 报告真实结果。

## 8. 因子评价：排名信息系数和五分组

定义位于 [factor_analysis.py](../src/quant_research/factor_analysis.py)。

### 8.1 什么是排名信息系数（RankIC）

对每个交易日：

1. 把股票按因子值排名；
2. 把股票按未来收益排名；
3. 计算两个排名的Spearman相关系数。

这个相关系数就是当天的排名信息系数（RankIC）。

```text
RankIC > 0：
因子高的股票，未来收益排名通常也高

RankIC < 0：
因子高的股票，未来收益排名通常更低

RankIC接近0：
因子与未来收益关系弱
```

### 8.2 信息系数稳定度（ICIR）是什么

```text
ICIR = RankIC平均值 / RankIC标准差
```

它不只关心平均预测能力，还关心稳定性。

如果某因子平均IC很高，但有时正得很强、有时负得很强，ICIR会较低。

当前训练加验证期结果：

| 因子 | 平均RankIC | 信息系数稳定度 | 解释 |
|---|---:|---:|---|
| `low_liquidity_20d` | 0.0255 | 0.146 | 样本中轻微正相关 |
| `reversal_5d` | 0.0077 | 0.046 | 非常弱 |
| `low_turnover_20d` | -0.0004 | -0.002 | 几乎无效 |
| `momentum_60d` | -0.0231 | -0.115 | 在这批样本中偏反转 |
| `momentum_20d` | -0.0286 | -0.161 | 同样偏反转 |
| `low_volatility_20d` | -0.0474 | -0.217 | 低波方向没有得到支持 |

这些数字不大，但金融因子本来就不会像物理测量一样有很高相关性。更重要的是稳定性、是否经济上合理，以及能否转化为组合收益。

### 8.3 五分组回测怎么看

每天按一个因子从低到高分成5组：

```text
第1组：因子最低
第5组：因子最高
```

然后看每组未来20日平均超额收益。

理想情况：

- 单调上升；
- 第5组明显高于第1组；
- 多年稳定。

当前五分组图在：

[factor_quintile_returns.png](../reports/factor_quintile_returns.png)

图中可以看到，部分因子的方向和初始经济假设并不一致，这说明因子研究不能只凭故事。

### 8.4 因子相关性

项目还计算每日6个因子两两之间的平均Spearman相关系数。

当前最明显的相关关系之一是：

```text
low_volatility_20d 与 low_turnover_20d：约0.58
```

说明低波动和低换手在样本中有一定重合。六个因子不是完全独立的信息来源。

## 9. 简单基线：为什么它能作为基准

定义位于 [models.py](../src/quant_research/models.py)。

基线分数：

```text
baseline_score
= (z_momentum_20d
 + z_momentum_60d
 + z_reversal_5d
 + z_low_volatility_20d
 + z_low_turnover_20d
 + z_low_liquidity_20d) / 6
```

也就是6个标准化因子等权相加。

为什么先做这个？

- 透明；
- 不需要训练；
- 不容易过拟合；
- 可以作为复杂模型的最低比较标准；
- 能帮助我们判断机器学习是否真的有增量。

如果AI模型跑不赢这个基线，就不能仅用回测收益证明AI模型更好。

## 10. 梯度提升模型是什么

项目使用：

```python
HistGradientBoostingRegressor
```

通俗理解：

> 模型把六个因子切成很多区间，寻找组合规则。例如“低流动性分数高、5日反转分数高、动量分数不过高”的股票排名可能更靠前。它由许多小决策树逐步修正错误。

模型的输入：

```text
6个标准化因子
```

模型的学习目标：

```text
当天的target_rank
```

模型不是直接预测股票涨多少，而是学习当天股票之间的相对排名。

### 10.1 模型参数

当前配置：

```text
最大迭代次数：200
学习率：0.04
最大叶子节点：15
叶子最小样本：100
L2正则：2.0
随机种子：42
```

- 学习率低：每次修正幅度小，更稳。
- 最大叶子少：模型复杂度低，防止过拟合。
- 叶子样本多：避免模型记住少数股票。
- L2正则：抑制参数过大。
- 固定随机种子：保证结果可复现。

### 10.2 为什么模型验证RankIC更高

验证期2022：

| 分数 | 平均RankIC | ICIR | 正IC比例 |
|---|---:|---:|---:|
| 梯度提升模型 | 0.0455 | 0.352 | 62.4% |
| 简单因子基线 | 0.0150 | 0.067 | 53.8% |

模型在“股票排名相关性”上明显更好。

### 10.3 为什么模型最终组合更差

在2023-2024测试期：

| 策略 | 年化收益 | 最大回撤 |
|---|---:|---:|
| 简单基线 | 31.34% | -10.77% |
| 梯度提升模型 | 22.78% | -24.41% |

可能原因：

- RankIC只衡量整体排序，不代表Top20误差最小；
- 模型可能优化了平均误差，但Top20承担了更大的尾部风险；
- 非线性关系在训练和验证期间成立，测试期失效；
- 组合是等权Top20，模型分数最高的尾部稳定性可能较差；
- 高换手和交易成本进一步放大差异。

这就是为什么模型评价和最终组合评价必须同时做。

## 11. 组合层：预测如何变成股票持仓

定义位于 [portfolio.py](../src/quant_research/portfolio.py)。

### 11.1 信号日

只取每个月的最后一个交易日：

```text
2023-01-31
2023-02-28
2023-03-31
...
```

在这些日期收盘后生成信号。

### 11.2 交易日期

取市场日历中的下一天：

```text
signal_date = 2023-01-31
trade_date  = 2023-02-01
```

这样保证：

```text
signal_date < trade_date
```

### 11.3 选股

对每个信号日：

1. 只保留 `eligible=True` 的股票；
2. 按分数从高到低排序；
3. 取Top20；
4. 等权分配。

### 11.4 权重

总股票仓位：

```text
95%
```

每只股票权重：

```text
0.95 / 20 = 0.0475 = 4.75%
```

剩下5%保留现金。

### 11.5 为什么不是每天调仓

每天换Top20会产生极高换手。真实交易有手续费和滑点，哪怕预测略好，也可能被交易成本吃掉。

项目第一版使用月度调仓，更接近可实际执行的中低频研究。

## 12. 回测层：一次交易如何计算

定义位于 [backtest.py](../src/quant_research/backtest.py)。

### 12.1 回测初始状态

```text
现金：1,000,000元
股票持仓：空
```

回测从第一次调仓的交易日开始。

### 12.2 每次调仓的顺序

1. 先卖出现有但目标权重不足的股票；
2. 降低超过目标权重的股票；
3. 再买入目标股票；
4. 更新现金；
5. 收盘后计算持仓市值；
6. 记录当日总资产和净值。

先卖后买可以补充现金，也避免先买入导致的临时资金不足。

### 12.3 100股一手

A股通常按100股为一手交易。

假设股票开盘价为10元，目标买入金额为47,500元：

```text
理论股数 = 47,500 / 10 = 4,750股
按100股取整 = 4,700股
```

不能买4,750股。

### 12.4 滑点

模型回测不会刚刚好按开盘价成交。

买入执行价：

```text
买价 = 开盘价 × (1 + 0.001)
```

卖出执行价：

```text
卖价 = 开盘价 × (1 - 0.001)
```

1000元买入的股票，买入成本先增加1元；1000元卖出则少收1元。

### 12.5 佣金

买入和卖出都收：

```text
佣金 = max(5元, 成交金额 × 0.0003)
```

成交金额小的时候最低收5元。这个最低佣金对小资金组合影响明显。

### 12.6 印花税

只在卖出时收。

项目按历史日期区分：

```text
2023-08-28之前：0.1%
2023-08-28及之后：0.05%
```

卖出成交金额10万元：

```text
旧税率印花税 = 100元
新税率印花税 = 50元
```

### 12.7 涨跌停和停牌

如果当天不能交易：

- 不买入；
- 不卖出；
- 原持仓继续保留。

项目按股票板块粗略设置价格限制：

- 科创板：20%；
- 创业板：2020-08-24之后20%，之前10%；
- 主板：10%。

真实回测还应处理ST、特殊交易日和精确涨跌停价，当前数据没有这些字段，所以项目只能做近似判断。

### 12.8 成交额上限

项目规定：

```text
单只股票交易金额 ≤ 当日成交额 × 5%
```

如果你计划买1000万元，但该股票当天只成交2000万元，那么最多买100万元。

这是为了避免回测假设自己能无限吃掉市场流动性。

### 12.9 每日估值

每天交易结束后：

```text
总资产 = 现金 + 每只股票持股数 × 当日收盘价
```

停牌时使用最近一次有效收盘价。

### 12.10 净值

```text
净值 = 当日总资产 / 初始资金
```

例如：

```text
初始 100万元
当天总资产 105万元
净值 = 1.05
```

## 13. 绩效指标怎么理解

定义位于 [metrics.py](../src/quant_research/metrics.py)。

### 13.1 总收益

```text
总收益 = 期末净值 - 1
```

简单基线期末净值约1.659：

```text
总收益约65.9%
```

### 13.2 年化收益

因为测试期不是完整自然年，需要换算成年化：

```text
年化收益 = (期末净值)^(252 / 交易日数) - 1
```

简单基线测试期约468个交易日，年化约31.34%。

年化不是保证每年都得到31.34%，而是把当前区间收益按复利速度折算。

### 13.3 年化波动

```text
日收益标准差 × sqrt(252)
```

简单基线年化波动约17.19%，模型约28.36%。

模型波动更大，承担的风险更高。

### 13.4 最大回撤

从某个历史最高净值，到之后最低净值的最大跌幅。

简单基线最大回撤：

```text
-10.77%
```

意味着在测试期最糟糕的净值高点到低点，组合曾经回撤约10.77%。

模型：

```text
-24.41%
```

虽然模型年化收益仍超过20%，但持有体验和风险明显更差。

### 13.5 夏普比率

当前计算：

```text
夏普 = 平均日收益 / 日收益标准差 × sqrt(252)
```

它衡量每单位波动能换到多少收益。

简单基线约1.67，模型约0.86。

夏普不是越高越好到可以忽略尾部风险，但同等收益下，波动和回撤更低通常更受欢迎。

### 13.6 Calmar比率

```text
Calmar = 年化收益 / 最大回撤绝对值
```

简单基线：

```text
31.34% / 10.77% ≈ 2.91
```

模型：

```text
22.78% / 24.41% ≈ 0.93
```

Calmar更关注“为了获得收益，承担了多大的深度回撤”。

### 13.7 主动收益

```text
策略净值 / 同区间基准净值 - 1
```

简单基线测试期相对等权股票池主动收益约24.36%。

注意，这不等于相对沪深300的超额收益。

### 13.8 跟踪误差

策略日收益与基准日收益之差的波动，年化后就是跟踪误差。

它衡量策略偏离基准的程度。

### 13.9 信息比率

```text
主动收益均值 / 主动收益标准差 × sqrt(252)
```

信息比率用主动收益除以跟踪误差，衡量相对基准的选股效率。

### 13.10 换手率

项目输出年化单边换手率。

简单基线约7.17倍，模型约7.85倍。

这意味着每月替换的股票比例很高，交易成本不可忽视。

## 17. 如何修改策略

主要参数位于 [base.json](../configs/base.json)。

### 修改持股数量

```json
"top_n": 20
```

改为30，就是每月选30只股票。每只等权权重会自动变为：

```text
0.95 / 30
```

### 修改预测周期

```json
"horizon_days": 20
```

如果改为10：

- 标签变为下一交易日开盘后的未来10个交易日；
- 训练集和验证集的Purge长度也自动变成10日左右；
- 因子经济含义可能改变，不能只改一个数字就认为结果一定有效。

### 修改成本

可以改：

- 佣金率；
- 最低佣金；
- 新旧印花税率；
- 印花税切换日期；
- 滑点；
- 成交额占比。

修改后必须重新运行，不要沿用旧结果。

### 增加新因子

需要在 `features.py` 中：

1. 增加因子定义；
2. 用历史数据计算；
3. 保证只使用T日及以前数据；
4. 做同日截面缩尾标准化；
5. 加入 `FACTOR_COLUMNS`；
6. 重新运行测试和分析。

新增因子后要看：

- 覆盖率；
- RankIC；
- ICIR；
- 分组单调性；
- 与其他因子的相关性；
- 是否改善扣成本后的组合收益。

## 18. 当前项目还有哪些不足

这是最重要的部分。一个合格研究项目不是“没有缺点”，而是知道缺点在哪里。

### 18.1 幸存者偏差

当前股票文件不是历史时点成分股。这是最大的限制。

### 18.2 基准不够严格

当前是股票池等权基准，不是真实沪深300或可交易ETF。

### 18.3 缺少行业数据

无法做行业中性化，也无法检查组合是否集中在一个行业。

### 18.4 缺少真实ST和精确涨跌停标志

当前只能根据代码和市场日期近似处理。

### 18.5 只用日频数据

没有分钟线、盘口、委托队列和真实成交回报。

### 18.6 因子数量少

六个技术因子只是研究起点。后续可以加入估值、质量、成长、分析师预期和事件因子。

### 18.7 换手率较高

年化单边换手超过7倍，对流动性和交易成本敏感。

### 18.8 测试期只有两年

2023-2024的结果不能代表未来所有市场状态，应继续做滚动样本外。

## 19. 面试时如何解释这个项目

一个简洁但完整的回答：

> 我构建了一个A股日频截面多因子研究框架，使用约287只股票和41.8万条股票-交易日记录。在T日收盘计算六个技术因子，使用T+1开盘作为交易起点，预测未来20个交易日的截面超额收益。训练集为2019至2021年，验证集为2022年，测试集为2023至2024年，并剔除未来标签跨越时期边界的样本。组合每月选前20只股票等权持有，回测包含佣金、日期相关印花税、滑点、100股取整、现金约束、近似涨跌停和成交额上限。最终简单因子基线在样本外年化约31.3%、最大回撤约10.8%，相对等权股票池主动收益约24.4%；梯度提升模型验证期排名信息系数更高，但组合收益和回撤更差。当前最大限制是股票池仍是当前成分文件，存在幸存者偏差，因此我不会把它表述为沪深300实盘超额收益。

如果面试官问“为什么基线比模型好”，回答：

> 排名信息系数衡量全截面排序，不等于前20只股票组合的收益。模型可能改善了平均排序，但在分数最高端不稳定，并承担了更大的尾部风险。测试期结果说明，复杂模型必须通过组合收益、回撤和成本检验，不能只看验证集排名信息系数。

如果面试官问“如何避免未来函数”，回答：

> 我按日期切分数据，用未来标签的`label_end_date`检查跨期，并在训练与验证之间剔除跨越边界的标签；回测要求`signal_date < trade_date`；标签从T+1开盘开始，而不是从T日收盘开始；测试集不参与模型拟合。

如果面试官问“还缺什么”，回答：

> 首要问题是历史时点成分股和退市股票；其次是真实沪深300基准、行业中性化、ST和精确涨跌停标志，以及滚动训练和成本敏感性检验。

## 20. 关键术语速查

| 术语 | 通俗解释 |
|---|---|
| 截面 | 同一天横向比较很多股票 |
| 时间序列 | 同一只股票沿时间比较 |
| 因子 | 可能预测未来收益的数字特征 |
| 标签 | 模型训练时希望预测的目标 |
| 未来函数 | 使用了信号生成时还不知道的信息 |
| 前复权 | 调整历史价格，降低分红送股造成的假跳变 |
| 训练集 | 用来拟合模型的数据 |
| 验证集 | 用来比较方案和调参的数据 |
| 测试集 | 最终检验模型的未参与训练数据 |
| 样本外 | 训练和调参没有使用过的数据 |
| 跨期标签剔除 | 删除与下一时间段重叠的未来标签 |
| 排名信息系数 | 因子排名和未来收益排名之间的相关系数 |
| 信息系数稳定度 | 因子信息系数的均值除以标准差 |
| 分层收益 | 按因子分5组或10组后比较未来收益 |
| 中性化 | 剔除行业、市值、市场等共同暴露 |
| 前N只股票 | 选择分数最高的N只股票 |
| 等权 | 每只股票配置相同资金比例 |
| 净值 | 当前资产相对初始资产的比例 |
| 最大回撤 | 从高点到后续低点的最大跌幅 |
| 夏普比率 | 每承担一单位波动获得多少超额收益 |
| 主动收益 | 策略收益与基准收益的差 |
| 跟踪误差 | 策略相对基准收益差的波动 |
| 信息比率 | 主动收益相对跟踪误差的效率 |
| 换手率 | 一段时间内持仓被替换的比例 |
| 滑点 | 理论价格和实际成交价格的差 |
| 市场冲击 | 自己的交易推动价格向不利方向发展 |
| 幸存者偏差 | 只用今天还存在的股票回测过去 |
| 历史时点信息 | 只使用当时真实可获得的信息 |
| T+1交易制度 | A股当天买入通常下一交易日才能卖出 |
| T日信号、T+1成交 | 今天收盘决策，下一交易日执行 |

## 21. 学完这份讲义的检查清单

你应该能够独立回答：
